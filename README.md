# hub-kb-plugin

LadderKit 知识库（hub-kb）的插件市场仓库，供 Claude Code、CodeBuddy 等宿主通过插件市场安装。

插件会在首个正式版本发布时推送到这里。安装方法以 https://ladderkit.dev/ 上的安装页为准。

This is the plugin marketplace repository for the LadderKit knowledge base (hub-kb). The plugin is published here with the first stable release; see https://ladderkit.dev/ for install instructions.
